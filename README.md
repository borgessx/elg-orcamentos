# ELG — Catálogo e Orçamentos

Sistema web para apresentação dos produtos e solicitação de orçamentos da ELG Caixas e Painéis Elétricos.

## Objetivo

Organizar o catálogo de caixas e painéis e registrar solicitações de orçamento com protocolo, facilitando o atendimento pelo WhatsApp.

## Status do projeto

Em planejamento e modelagem do banco de dados.

Etapa atual: construção do Diagrama Entidade-Relacionamento (DER).

## Escopo da primeira versão

- Cadastro de clientes e endereços.
- Catálogo de produtos com categorias, medidas e imagens.
- Lista de produtos para solicitação de orçamento.
- Registro de orçamentos com itens, quantidades e valores.
- Geração de protocolo.
- Encaminhamento do atendimento ao WhatsApp.
- Registro de solicitações personalizadas.
- Área interna para gerente e funcionários.
- Preservação dos dados históricos dos orçamentos.
- Interface responsiva.

## Fora do escopo da primeira versão

- Controle de estoque.
- Gestão da produção.
- Processamento de pagamentos.
- Emissão de notas fiscais.
- E-commerce com checkout.
- CRM completo.
- Armazenamento de anexos enviados pelos clientes.

## Tecnologias definidas

- Python
- Django
- PostgreSQL
- Git e GitHub

## Fluxo principal

1. O cliente consulta o catálogo.
2. Seleciona produtos e informa as quantidades.
3. Envia a solicitação de orçamento.
4. O sistema salva os dados e gera um protocolo.
5. O cliente segue para o atendimento pelo WhatsApp.

Solicitações de produtos personalizados são encaminhadas ao atendimento conforme a necessidade do cliente.
